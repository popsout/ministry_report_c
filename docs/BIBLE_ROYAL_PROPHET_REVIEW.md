# 왕정 시대부터 귀환 이후까지 — 요약과 예언자 활동 겹침 대조

2026-10-27. 제공 한국어 신세계역의 본문·표제·책 개요·성경 일람표와 부록 가6을 기준으로 왕정·유배·귀환의 21개 요약을 보완했다. 앞서 정리한 왕정 이전 15개와 합쳐 전체 36개 사건이 각각 4~6문단의 학습 요약을 갖는다. 신세계역 전문을 복제한 것이 아니며, 모든 주장·세부 연대·최신 공식 해설의 검증 완료본은 아니다. 모든 사건의 전체 검토 상태는 계속 초안이다.

## 예언자 대조

예언서 16권의 필자와 엘리야·엘리사의 활동 배경 18건을 별도 표로 정리했다. 나라·도시·왕·본문의 재위년·서로 겹치는 범위·불확실성·출처를 구분했다. 기존 화면의 사건별 설명과 성구·배치 안내에도 중요한 결과를 반영했다. 이 표를 읽는 순서가 모든 발언의 절대 시간순이라는 뜻은 아니다.

- 호세아·아모스·이사야·미가의 왕명과 활동 배경 일부가 겹친다. 모든 발언을 같은 해로 날짜 붙이지 않는다. 요나의 여로보암 2세 문맥과 니네베 방문의 정확한 해도 구별한다.
- 요엘의 820년경(?)은 출처의 잠정 배치이며 왕명은 본문의 직접 진술이 아니다.
- 스바냐의 요시야 배경과 예레미야의 요시야 제13년 시작을 구분한다. 나훔·하박국·오바댜는 왕의 재위년이 같은 방식으로 본문에 명시되지 않아 도표의 넓은 배경을 넘는 세부 발언 날짜를 단정하지 않는다.
- 예레미야·에스겔·다니엘은 서로 다른 장소에서 같은 큰 시대의 일부를 다룬다. 에스겔의 활동을 예루살렘 멸망 뒤에만 시작된 것으로 쓰지 않는다.
- 학개와 스가랴는 같은 재건기이다. 다리우스 제2년 여섯째 달의 학개, 여덟째 달의 스가랴, 아홉째 달의 학개를 대조했다. 에스라 5장의 공동 활동과 연결한다.
- 말라기의 기록완료 443년 이후를 모든 발언의 연도로 변환하거나, 비슷한 문제를 다뤘다는 이유만으로 에스라·느헤미야와 특정 날짜에 동시 활동했다고 확정하지 않는다.

## 시간순으로 읽을 때 바로잡은 부분

1. 예레미야 32:1은 시드기야 제10년이나 36:1은 그보다 앞선 여호야김 제4년이다.
2. 에스겔 29:17은 제27년, 40:1은 유배 제25년이다. 책의 뒤쪽이 언제나 나중 날짜인 것은 아니다.
3. 다니엘 7~8장의 벨사살 제1년·제3년 환상은 5장의 함락 이전 왕의 시대이다. 9장은 다리우스 제1년, 10장은 키루스 제3년이다. 환상을 받은 때와 미래 성취 내용은 구분하며 6장과 9장 사이의 세부 순서를 재위년 정보만으로 고정하지 않는다.
4. 열왕기하 18:1,9~10에 따라 히스기야의 통치는 사마리아 함락 이전부터 시작된다. 북왕국 말기와 히스기야 항목은 겹친다.
5. 다윗이 유다의 왕이 된 단계와 온 이스라엘을 다스린 단계를 구분한다. 사무엘하 책의 시작 연도를 온 이스라엘 즉위일로 일괄 바꾸지 않는다.
6. 요엘 참조에서 빠졌던 3장을 포함했다. 에스더의 아하수에로 동일시는 제공 각주의 ‘크세르크세스 1세인 것 같음’을 보존했다.
7. 귀환·성전·성벽 재건은 페르시아 통치 아래의 공동체이다. 이를 독립된 다윗계 통일 왕국의 재성립으로 표시하지 않는다. 에스겔의 회복 예언도 당시 이미 일어난 정치적 재통합과 구분한다.
8. 동명이인인 유다와 북이스라엘의 왕들, 예언자 호세아와 왕 호셰아, 예언서 미가와 이믈라의 아들 미가야, 두 다리우스와 두 여호수아를 나라·직책·본문 문맥으로 구별한다.

## 산출물과 적용 상태

개인 산출물은 `private-import/bible-study-review.md`(전체 요약), `bible-prophet-overlaps.md`와 JSON(대조표), `bible-review.html`(독립 미리보기)이다. 본문 PDF·사건 데이터·수입 SQL은 Git이나 공개 앱 번들에 넣지 않는다.

추가한 한정된 근거는 44건으로 전체 176건이다. 개요에서 확인한 큰 사건 구성과 본문에서 확인한 명시 날짜를 같은 검증 수준으로 설명하지 않는다. 근거 수는 전체 검증 완료 사건 수가 아니다. 미확정 절대연도와 상징의 모든 성취 해석은 여전히 보류한다.

`bible-study-update.sql`은 전체 36개와 새 사무엘 항목을 한 번에 넣을 수 있도록 준비한 데이터 전용 트랜잭션이다. 기존 관리자·정책·계정·봉사 기록은 변경하지 않으며, 운영 SQL과 사이트 데이터 배포는 사용자 요청대로 실행하지 않았다. 정리본 검토 후 하나의 파일을 적용하면 되므로 과거 족장 전용 SQL을 따로 실행할 필요가 없다.

검사: 실제 자료 파서, 36개 요약의 문단과 범위 보존, 예언자 18명의 고유 항목을 확인했다. 새 사무엘 항목 삽입·전체 자료 대조·반복 실행·관리자/비관리자 접근·봉사 기록 보존은 격리된 로컬 PostgreSQL에서 확인했다. 원격 운영 서버에 적용한 결과와 구분한다.
