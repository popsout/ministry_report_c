# 개인 목표 보드

첫 화면은 개인 목표 보드이며 `#/goals`로 접근합니다. 운동 타이머는 독립 메뉴 `#/timer`로 분리했으며, 기존 봉사 기록은 `#calendar`에 유지합니다. 성경 시간순 읽기는 메뉴에서 제외했으며 관련 데이터, SQL, 저장 모듈은 보존했습니다.

- 목표 이름과 수행일 수(1~365)를 설정합니다. 왼쪽 START와 오른쪽 GOAL 사이에 수행일 수만큼 칸이 생깁니다. 한 줄로 이어진 풍경과 길 위에서 깃발 캐릭터가 좌우로 움직이며, 모바일에서도 전체 경로가 보입니다.
- 날짜마다 ＋(1), 스테이(0), －(-1) 중 하나를 저장합니다. 오늘과 과거 날짜를 평가할 수 있습니다.
- 같은 날짜를 다시 평가하면 기존 값을 대체합니다. 날짜 오름차순으로 전체 기록을 다시 계산하며, 매 단계 위치를 0~목표 칸 사이로 제한합니다.
- － 평가가 있는 날짜 수를 누적 실패로 표시합니다. 3일 이상이면 강조된 시각 알림과 단호한 격려를 표시합니다. 평가를 수정하면 누적 실패도 다시 계산합니다.
- 목표 설정을 변경해도 평가 기록은 보존합니다. 별도 초기화 기능은 없습니다.
- 휴식 타이머는 90초·2분·3분, 일시정지·계속·초기화를 지원합니다. 절대 종료 시각으로 남은 시간을 계산하여 백그라운드 지연을 보정합니다. 종료 시각을 브라우저에 저장하므로 페이지 이동·새로고침 후에도 유지됩니다. 완료 시 최대 30초 동안 반복되는 차임과 모든 화면에서 보이는 ‘알람 끄기’ 배너를 제공하며 알림을 허용한 브라우저에서는 시스템 알림도 표시합니다. 모바일에서 브라우저 실행이 중단되거나 앱이 종료되면 정시 알람은 보장하지 않으며, 복귀 시 만료를 확인합니다. 서버 푸시 예약은 구현하지 않았습니다. 알람을 끄거나 타이머를 다시 시작·초기화하면 예약된 소리도 취소합니다. 다른 앱의 음악을 일시정지하는 OS 권한은 웹에서 제공하지 않으므로 음악 중단·음량 감소는 보장하지 않습니다.

## 저장과 보존

온라인 모드에서는 **같은 Supabase 계정으로 로그인한 기기끼리 목표 이름·수행일 수·날짜별 평가를 공유**합니다. 기존 `personal_journals.document`의 선택 항목 `goals`로 저장합니다. 기존 봉사 문서(목표 항목 없음)도 그대로 읽으며, 목표 저장은 봉사 기록·설정·알 수 없는 문서 항목을 보존하고 봉사 저장은 목표를 보존합니다. 목표와 봉사는 문서의 동일한 revision을 사용해 동시 수정 충돌을 차단합니다. 충돌 시 저장 실패를 표시하고 온라인 새로고침 후 다시 평가할 수 있습니다.

실시간 구독, 화면 복귀·네트워크 복구 시 재조회, 15초 주기 재조회와 ‘온라인 목표 새로고침’을 사용합니다. 온라인 저장 실패 시 로컬 저장 성공으로 대신 처리하지 않습니다. 서버 인증·RLS 정책·기존 봉사 테이블은 변경하지 않으며 DB 마이그레이션도 필요하지 않습니다. 타이머 실행 상태는 해당 기기에서만 유지됩니다.

로그인하지 않았거나 한 기기 모드인 경우 기존 `chagok.goals.v1` 로컬 기록을 사용합니다. 이전 온라인 화면에서 로컬 저장한 `.사용자UUID` 키도 보존합니다. 로그인 후 ‘이 기기의 이전 목표 기록 가져오기’를 누르면 계정 키 우선, 없으면 기본 키의 기록을 가져옵니다. 온라인 목표가 이미 있다면 온라인 목표 설정과 겹치는 날짜의 온라인 평가를 유지하고 없는 날짜만 추가합니다. 온라인 목표가 없으면 로컬 목표 전체를 가져옵니다. 가져오기 후에도 로컬 원본은 삭제하지 않습니다. 예시 화면은 계정·실제 기록과 분리됩니다.

다른 기기도 최신 화면으로 새로고침한 뒤 사용해야 합니다. 목표 동기화 이전 버전은 문서에 목표 항목을 보존하지 못할 수 있습니다.

## 검증

`npm test`, `npm run build`, `CHROMIUM_PATH=/usr/bin/chromium npx playwright test e2e/goal-sync.spec.ts e2e/cloud.spec.ts e2e/personal-goals.spec.ts e2e/local.spec.ts e2e/journal.spec.ts e2e/goals.spec.ts e2e/reset.spec.ts`

기존 봉사 테스트는 새 첫 화면 도입에 맞춰 `#calendar`로 진입합니다. 운영 배포는 별도 단계입니다.

캐릭터는 사용자가 제공한 곰 이미지를 바탕으로 배경을 투명화한 웹 이미지입니다. 평가 버튼은 이동 방향에 맞춰 － / 스테이 / ＋ 순서로 배치합니다.

격려 문구 42개를 일상·＋·스테이·－·목표 달성 상황에 맞춰 제공합니다. 날짜와 진행 상황에 따라 문구가 바뀌며, ‘다른 격려 보기’로 넘길 수 있습니다. 식사량 사전 결정, 추가 주문·간식·단 음료 조절, 주말 외식 계획 등 구체적인 식단 실천을 강조합니다. 스테이는 다음 식사에서 바꿀 행동을 정하도록 독려하며, 체중 정체를 칭찬하거나 감량 결과를 보장하지 않습니다.
