# 학습용 성경 사건 지도 — 내용 검증 기준

상태: 검증 준비 및 원문 접근 대기. 기존 34개 사건과 연대는 편집 초안이며 학습용 검증본이 아니다. 프로그램 테스트와 내용의 사실 검증은 구분한다.

## 방법

모델을 재학습하거나 같은 질문에 여러 번 답하게 하는 것으로 정확성을 증명하지 않는다. 신세계역의 관련 성구와 여호와의 증인 공식 출판물의 실제 문단을 읽고, 주장별로 근거를 기록하는 방식을 사용한다. 자료를 정리·검색·대조하는 데 AI를 사용하되, 모델의 기억이나 다른 AI의 동의만을 출처로 채택하지 않는다.

현재의 비공개 작업 자료는 `private-import/bible-verification-ledger.json`과 `private-import/bible-verification-audit.md`이다. 자료의 해시를 기록했으므로 내용이 바뀌면 관련 근거도 다시 검토한다. 원본 PDF나 추출 본문을 공개 저장소에 넣지 않는다.

## 검증을 나누는 단위

- 성구 대응: 동일 사건의 병행 기록 / 같은 시대의 배경 / 별개의 사건 / 회고 서술을 구분한다.
- 요약: 각 문장의 사실을 연결 성구에서 확인하고, 본문에 없는 설명이나 인과를 추가하지 않는다.
- 통치자·예언자: 해당 나라·직함·동일 인물·재위 또는 활동 시기와 카드의 사건을 대조한다. 넓은 시대의 인물 명단을 특정 날짜의 동시 활동 명단으로 취급하지 않는다.
- 사건 배치: 명시된 선후관계, 출판물의 배치, 편집자의 추론을 구분한다. 여러 책을 섞어 새 성경 문장을 만들지 않는다.
- 연대: 절대연도, 기간·범위, 상대적 순서, 시대 미상, 아직 확인하지 못함을 구분한다. 연도가 없더라도 시대를 알 수 있으면 시대를 표시한다.
- 기준 체계: 여호와의 증인 출판물의 연대 체계를 따른다. 일반 역사학의 다른 연도를 무의식적으로 섞지 않으며, 차이가 학습에 중요하면 구분해서 설명한다.

## 근거 한 건에 기록할 정보

1. 검토할 주장과 적용하는 사건 ID.
2. 공식 출처 URL, 정확한 자료 제목·판본·발행 정보와 해당 쪽/항목/문단 또는 성구.
3. 원문을 실제 확인한 날짜와 그 자료가 명시하는 내용의 짧은 요약. 검색 결과 제목만으로 원문 확인을 대신하지 않는다.
4. 직접 명시 / 연산·추론 / 근거 부족의 구분. 연산은 출발 연대·기간·가정과 기원전/기원후의 0년 부재 등을 기록한다.
5. 해당 근거가 입증하는 부분과 입증하지 못하는 부분. 집필 시기를 사건 발생 시기로 바꾸어 쓰지 않는다.
6. 채택 / 수정 / 보류의 판정과 이유. 불일치하는 공식 자료가 있으면 발행 시점과 적용 범위를 확인한다. 단순히 더 최신이라는 이유만으로 무조건 덮어쓰지 않는다.

## 우선순위

1. 욥기: 현재의 기원전 17~15세기 범위와 족장 시대 부근 배치는 미검증이다. 근거를 확인하기 전 확정 학습 사실로 제공하지 않는다.
2. 기원전 607년·537년, 출애굽·왕국 분열 등 연대표의 기준점: 실제 공식 출판물 근거와 카드의 적용 범위를 확인한다.
3. 에스더·페르시아 왕들의 재위 기산, 에스라·느헤미야 사건 시기: 인물 동일시·공동 통치·사건/집필 시기를 구분한다.
4. 열왕기·역대기의 병행 사건과 예언서의 재배치: 큰 묶음 안에서도 직접 대응하는 성구와 추가 내용을 따로 확인한다.
5. 바벨·창조·요엘 등 불확실한 항목: 자료 미확보를 역사적 미상으로 표시하지 않는다. 확인 결과에 따라 상대적 시대 또는 미상으로 남긴다.

## 통과 기준

모든 채택 주장에 실제 읽은 근거가 있어야 한다. 다른 기록과의 모순·인물 혼동·연대 체계 혼용 여부를 별도 대조하는 두 번째 검토를 수행한다. 같은 출처를 반복 확인하는 것만으로 독립적인 교차 검증이라고 부르지 않는다. 같은 기관의 여러 출판물도 역사학계 전체의 합의로 표현하지 않는다.

사건의 요약·통치자·성구가 확인되었다고 그 사건의 절대연도까지 확인 완료로 바꾸지 않는다. 근거가 부족한 값은 제거·유보하고 설명을 남긴다. 완전한 무오류를 보증하지 않으며, 남는 불확실성과 수정 이력을 사용자에게 보이게 한다. 사용자에게 전문 검수를 전가하지 않는다.

## 현재 차단된 작업과 필요한 자료

이 환경은 2026-10-26 공식 JW 사이트 및 온라인 라이브러리 접근 시 프록시 403을 반환했다. 접근 허용 대상으로 `jw.org`, `www.jw.org`, `wol.jw.org`를 지정한 환경 설정 초안을 준비한다. 이는 열람을 위한 허용이며 사이트의 자료 이용 조건이나 접근 통제를 우회하는 허용이 아니다. 설정 저장 이후에도 실제 HTTPS 요청이 성공해야 원문 검증을 시작할 수 있다.

사용자 보유 PDF는 판권·판본과 해당 구간 원문 대조를 위해 필요하다. 역대기하 15장 일부까지의 파일만으로 욥기·예언서와 히브리어 성경 전체를 검증할 수 없으므로 공식 온라인 원문도 확보해야 한다. PDF는 아직 제공되지 않았다. PDF 수령과 공식 접근 후 장절·본문·판본을 확인하며, 전문 저장·재제공 조건의 확인도 별도로 수행한다.

기존 연대 초안의 수입 SQL을 실행했다고 검증본이 되는 것은 아니다. 원문 대조가 끝나기 전에는 학습 자료로 확정 사용하지 않도록 안내한다.
