# 제공 PDF 대조 — 1차 결과 (2026-10-26)

> 마지막 172쪽 파일 수령 전의 단계별 기록입니다. 현재의 부록 포함 자료와 추가 검증 결과는 [일람표·부록 대조 보고서](BIBLE_APPENDIX_REVIEW.md)를 따릅니다.

상태: **검증 진행 중. 전체 사건·연대 검증 완료본이 아니다.** 원문을 확인한 한정된 내용과 추가 해석이 필요한 내용을 구분한다.

## 자료 확인

- 첫 파일 600쪽, 둘째 파일 600쪽, 셋째 파일 400쪽으로 총 1,600쪽이다.
- 표제·판권: 한국어 개정판 2014년, 2026년 인쇄본. 첫 파일 3·4쪽에서 확인했다.
- 첫 연결부는 역대기하 15:15 → 15:16, 둘째 연결부는 다니엘 6:21 → 6:22로 이어진다.
- 히브리어·아람어 성경은 인쇄 1287쪽 말라기 4:6까지 있고, 그 끝이라는 표지도 확인했다. 인쇄 1242~1243쪽의 오바댜도 포함된다.
- 마지막 인쇄 1600쪽은 히브리서 4:8–5:12이다. 신약 끝과 연대표·지도 등 후속 부록은 제공되지 않았다. 따라서 성경책 배열·본문은 확인할 수 있으나 이 자료에 연대표 부록까지 들어 있다고 가정하면 안 된다.
- 파일별 해시, 추출 텍스트, 페이지 위치 인덱스와 상세 감사 기록은 Git에서 제외한 `private-import/pdf-audit/`에 보관한다. 본문이나 PDF를 공개 저장소·정적 사이트에 넣지 않았다.

두 단 본문 사이에 상호 참조가 들어 있어 일반 텍스트 추출만으로 행을 읽으면 서로 섞인다. 글자 크기·좌표로 본문 칸을 분리하는 추출물을 보조 자료로 사용했다. 이것을 곧 출판 가능한 장절 본문으로 취급하지 않는다. 성구 검토에는 해당 페이지와 앞뒤 문맥을 함께 사용했다.

## 사이트와 자료의 처리

13개 사건에 29건의 원문 대조 기록을 추가했다. 각 기록은 성구, 파일명, 파일 안의 쪽수, 인쇄 쪽수, 확인 내용, 확인하지 못한 범위를 포함한다. 한 사건에 기록이 붙어도 사건 전체가 검증 완료라는 뜻은 아니다.

그중 8개 사건의 주 연대 표시는 본문이 직접 명시하는 재위년·배경으로 바꾼다. 미검증 절대연도는 주 표시에서 ‘연대 검증 중’으로 보류하고, 기존 초안 값과 이유는 상세 정보·감사 기록에서 확인하도록 한다. 자료 미확보와 역사적으로 시대 자체를 모르는 경우를 구분한다. 사건 요약의 전체 검토 상태는 여전히 초안이다.

기존 관리자 등록을 완료한 경우 비공개 산출물 `private-import/bible-verification-update.sql`로 정정·근거 자료를 반영한다. 아직 초기 등록 전이면 갱신된 `private-import/bible-setup.sql`을 사용한다. 운영 DB에 자동 적용하지 않았다. 오프라인 서가는 온라인에서 다시 저장해야 최신 정정 내용이 반영된다.

## 남은 검증

- 기존 252개 검토 항목 전체를 이 29건의 원문 확인만으로 완료 처리하지 않는다. 수입 데이터·본문 연결·인물·요약은 항목별 검토가 더 필요하다.
- 절대연대의 기준점, 욥기·요엘·에스더 등의 세부 배치, 페르시아 왕들의 재위 기산, 열왕기·역대기의 세부 동시대 관계를 공식 출판물에서 대조해야 한다.
- 공식 JW/WOL 접근은 현 실행 환경에서 아직 허용되지 않았다. 이미 준비한 환경 변경 초안의 적용 후 실제 접근을 재확인해야 한다. 성경 PDF를 받았다는 이유만으로 이 차단이 해소된 것은 아니다.
- PDF 판권의 ‘판매용 아님’은 별도 사이트의 전문 저장·재제공 허락과 같지 않다. 실제 성경 본문 게시나 오프라인 전문 저장은 이용 조건 확인 전까지 추가하지 않았다.
