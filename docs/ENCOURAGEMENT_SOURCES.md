# 다이어트 동기부여 70선 — 문구와 출처 확인 상태

현재 문구는 차곡을 위해 직접 작성한 한국어 문구 70개입니다. 외부 명언을 인용하거나 특정 인물의 말로 표시하지 않습니다. 목표 설정·식사 분량·간식·주말 외식·환경 준비·식단 재정비·자신감의 7개 묶음에 각각 10개씩 있습니다.

## 인터넷 자료 확인 상태

2026-11-10(한국 시간) CDC와 NHS 자료에 접속을 시도했으나 환경 프록시의 HTTP CONNECT 403으로 차단됐습니다. 아래 링크는 **참고 후보이며 본문 확인이나 문구별 근거 대조를 완료하지 않았습니다**. 인터넷에서 수집한 문구 70개라고 주장하지 않습니다.

- CDC, Losing Weight: https://www.cdc.gov/healthy-weight-growth/losing-weight/index.html
- NHS, Tips to help you lose weight: https://www.nhs.uk/live-well/healthy-weight/managing-your-weight/tips-to-help-you-lose-weight/
- NIDDK, Changing Your Habits for Better Health: https://www.niddk.nih.gov/health-information/diet-nutrition/changing-habits-better-health

환경 설정 초안에 기존 Supabase 도메인을 보존하고 위 세 기관과 배포 사이트의 접속 허용을 추가했습니다. 검토·저장·환경 게시 후 새 연결에서 다시 확인해야 합니다. 승인 및 실제 읽기 전에는 아래 문구를 ‘인터넷 자료를 검토했다’고 수정하지 않습니다.

인터넷 자료 확인이 가능해지면 문장을 그대로 복사하지 않고 식사 조절 행동을 독려하는 짧은 한국어로 재구성하고, 실제 검토한 출처와 날짜를 여기에 기록합니다.
