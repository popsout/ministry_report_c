# 왕·예언자·병행 기록의 추가 대조

2026-10-26. 제공 신세계역을 기준으로 수행한 한정된 원문 대조이며, 사건 요약 전체의 검증 완료 선언이 아니다.

## 라못길르앗 전쟁의 문의

열왕기상22:1~8(전체 PDF503~504쪽)과 역대기하18:1~8(602~603쪽)은 이스라엘왕 아합과 유다왕 여호사밧의 전쟁 논의를 연결한다. 같은 넓은 시대에 속한다는 이유만으로 연결한 것이 아니라, 두 왕과 전쟁 장소·문의가 대응하는 구간을 확인했다.

문의하는 예언자는 ‘이믈라의 아들 미가야’로 식별한다. 역대기하17:7의 교육 파견 방백 목록에도 미가야라는 이름이 있으므로, 이름만 검색해 첫 등장 인물로 합치지 않는다. 이 두 사람의 관계를 해당 구절만으로 확정하지 않으며, 카드에는 예언자의 부칭을 명시했다.

## 히스기야와 산헤립

열왕기하18:13(534쪽)과 이사야36:1~2(970쪽)는 히스기야 제14년과 아시리아왕 산헤립의 침공을 명시한다. 역대기하32:1(620쪽)도 같은 통치자와 유다 침공을 연결하지만, 그 절 자체에는 제14년이라고 적혀 있지 않다. 정보를 공통 사건으로 묶되 어느 기록이 어떤 정보를 더 제공하는지 구분한다.

## 예루살렘 멸망의 단계

열왕기하25:2~9(545쪽)과 예레미야52:5~13(1108쪽)은 포위·함락과 느부사라단 관련 기록을 다룬다. 다섯째 달 날짜 표현은 열왕기하25:8의7일과 예레미야52:12의10일로 구분해 보존한다.

이 숫자들을 하나로 바꾸거나, 차이의 이유를 모델의 기억으로 설명하지 않았다. 공식 출판물의 해설을 추가 대조하기 전에는 방문·집행의 각 단계가 정확히 어느 날이라는 해석을 확정하지 않는다. 같은 멸망 흐름을 묶는 것과 모든 세부사항을 동일한 표현으로 합치는 것은 다르다.

## 화면 확인과 실제 서버 상태

운영 Supabase의 공개 클라이언트 설정으로 읽기 전용 확인을 수행했다. `bible_reading_events`는 PGRST205, `is_bible_admin`은 PGRST202를 반환해 해당 객체가 API 스키마 캐시에 없는 상태였다. 따라서 현재 운영 사이트의 준비 중 화면을 관리자 콘텐츠가 연결된 실제 화면이라고 설명하지 않았다. 이 확인은 사용자의 로그인 세션이나 DB 관리 권한을 사용하지 않는다.

실제 읽기 화면의 표시 코드를 `BibleReadingContent`로 분리해 인증된 앱과 개인 검토 미리보기에서 공유한다. 공개 사이트의 인증·서버 정책은 그대로 유지한다. 앱이 준비 중일 때 로그인한 사용자의 본인 UID를 복사할 수 있는 안내를 추가했다. UID 복사나 화면 표시가 관리자 권한 부여를 대신하지 않는다.

개인 미리보기는 `node scripts/build-reading-review.mjs`로 생성하는 `private-import/bible-review.html`이다. Git·dist·gh-pages에서 제외되며 신세계역 전문이나 지도 이미지를 넣지 않았다. 사건 요약·참조·검증 안내만 들어 있는 암호화되지 않은 개인 검토 파일이다. 서버에 연결하지 않고 독립적으로 눌러볼 수 있으며, 로그인·기기별 암호화 서가 기능을 흉내 내지 않는다. 실제 서비스의 접근 제한을 대체하거나 우회하는 경로는 추가하지 않았다.

미리보기와 운영 앱은 같은 본문 표시 코드를 사용한다. 모바일에서는 사건을 선택하면 해당 내용이 보이는 위치로 이동한다. 초기 생성 파일을 브라우저에서 확인해35개 사건·8개 시대, 클릭 탐색, 화면 넘침 여부, 초기 문서 외 네트워크 요청 없음과 자바스크립트 오류 없음을 확인했다. 실제 신세계역 본문 읽기 및 전체 해석 검증이 완료됐다는 뜻은 아니다.
