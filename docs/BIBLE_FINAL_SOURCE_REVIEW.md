# 2026-10-27 추가 정밀 대조와 적용 준비

이번에는 공식 워치타워 온라인 라이브러리 접속이 가능해져 제공 신세계역 PDF 대조에 공식 해설 11개를 더했다. 12개의 사건별 공식 해설 참조를 만들고 원문·표제 근거 14건을 추가했다. PDF 대조 기록은 전체 190건이다. 숫자는 전체 검증 완료 사건 수가 아니며, 36개 사건의 요약 전체 상태는 계속 초안이다.

## 중요한 정정

앞선 초안의 ‘에스라4장은 후대 왕들의 서신이 들어 있으므로 중간에 미래로 갔다 돌아온다’는 설명은 여호와의 증인 공식 해설을 확인하기 전에 성급하게 채택한 것이었다. 이 설명을 현재 자료에서 제거했다. [「에스라서의 주요점」](https://wol.jw.org/ko/wol/d/r8/lp-ko/2006044#p15)은 공사 중단522년, 재개520년, 완공515년으로 설명한다. 왕 목록은 에스라4장의 아하수에로를 캄비세스와, 아닥사스다를 바르디야 또는 가우마타와 연결한다. 에스더와 에스라7장 이후의 동명 왕들을 자동으로 동일시하지 않는다.

제공 성경의 왕명 표기와 본문 자체의 날짜는 그대로 두고, 왕의 역사적 동일시와 기원전 연도는 해당 공식 해설에 근거한 설명으로 구분했다. 과거 PDF만으로 보류한 항목도 온라인 설명을 대조한 범위에서 갱신했다.

## 구체화한 연대·배경

- 성전 완공515년과 에스라 귀환468년은 [「통찰」 에스라서](https://wol.jw.org/ko/wol/d/r8/lp-ko/1200001476#p9)의 설명을 대조했다.
- 느헤미야서의 시작 소식456년과 출발455년, 제32년443년을 [「통찰」 느헤미야서](https://wol.jw.org/ko/wol/d/r8/lp-ko/1200003213#p5)에서 구분했다.
- 나훔은632년 니네베 멸망 전의 기록, 하박국은628년경 기록 추정, 오바댜는607년이 가장 가능성 있는 기록 연대라는 공식 설명을 보존했다. 이를 모든 발언의 날짜로 바꾸지 않았다.
- 요엘820년경은 공식 해설도 단정하지 않는다. 말라기는 재건된 성전·총독의 문맥에 근거한 귀환 이후 배경과443년 이후 기록 추정을 구분했다.
- [엘리야의 이동과 편지](https://wol.jw.org/ko/wol/d/r8/lp-ko/2005562#p12)는 공식 설명에 따라 죽음으로 다루지 않는다. 유다 왕 여호람과 북왕국의 동명 왕은 구분한다.
- [다니엘1:1의 여호야김 제3년](https://wol.jw.org/ko/wol/d/r8/lp-ko/1200002377#p7)은 예속된 왕으로서의 제3년인 것 같다는 공식 해설의 추정 수준을 유지한다.

## 병행 기록·시가서

- 사사기20:28의 비느하스 정보를 추가해 책 끝 사건을 삼손 뒤로 고정하지 않는다.
- 잠언25:1의 히스기야 사람들의 옮겨 쓰기, 30:1의 아굴, 31:1의 르무엘을 확인했다. 원래 저술·옮겨 쓰기·여러 표제를 구분한다.
- 사무엘하22장과 시편18편의 구출 배경을 연결했다. 사무엘하21~24장을 모두 압살롬 뒤의 엄격한 시간순이라고 단정하지 않는다.
- 다윗 인구조사의 서로 다른 수치는 원문대로 보존했다. [「통찰」 등록](https://wol.jw.org/ko/wol/d/r8/lp-ko/1200003676#p13)의 계수 범위 등 가능한 설명을 확정적 해결로 바꾸지 않았다.
- 에스라의 예수아와 학개·스가랴의 여호수아는 여호사닥의 아들인 대제사장이라는 문맥으로 연결하며, 모세의 후계자와 구분한다.

## 남겨 둔 제한

제공2026년 부록의 요시야 재위 경계는628년이지만 「통찰」 하박국서8항에는629년으로 적혀 있다. 이를 숨기거나 평균 내어 새 연도를 만들지 않았다. 왕의 도표는 제공 부록 기준을 유지하며 하박국628년경은 해당 해설의 기록시기 추정으로 별도 제시했다. 완전한 기산법 비교는 확인할 여지가 남는다.

온라인 문서가 존재한다는 사실을 모든 세부 해석의 독립 검증으로 부르지 않는다. 읽은 문단·확인한 주장·추정 수준·확인일은 개인 산출물 `bible-online-sources.json`에 기록하고 원문 스냅샷의 해시도 보관했다. 출판물 원문은 공개 저장소와 번들에 넣지 않는다.

## 화면과 적용

공식 출판물에 직접 가는 선택적 URL을 기존 성구 자료 안에 넣었다. 새 DB 열 없이 저장할 수 있고 이전 성구와 암호화 서가도 계속 읽는다. URL은 HTTPS의 한국어 WOL 출판물 주소만 허용하며 임의 호스트·스크립트·사용자정보가 든 URL은 거부한다. 오프라인에서는 외부 링크를 계속 비활성화한다.

`bible-study-review.md`, 예언자 대조표, 개인 미리보기와 전체36개 데이터 전용 SQL을 갱신했다. 운영 DB 적용은 아직 보류한다. 코드만 배포해도 실제 요약은 소유자가 일괄 SQL을 실행하기 전에는 바뀌지 않는다.

검사 결과: 자료·URL 검증과 DB 접근 단위 검사6개, 관리자 읽기·오프라인 서가·로그아웃 브라우저 검사6개, 실제 배포 빌드의 오프라인 재실행1개 통과. 실제36개 자료는 네 화면 너비에서 넘침 없이 확인했고, 일괄 SQL의 재실행·새 항목 추가·값 보존·RLS·봉사 기록 보존은 로컬 DB에서 확인했다. 운영 SQL 실행 결과를 뜻하지 않는다.
