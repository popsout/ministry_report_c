# 신세계역 일람표·부록 대조 (2026-10-26)

상태: **해당 연대 표기와 근거의 대조 결과. 모든 사건·해석의 검증 완료 선언은 아님.** 기준은 사용자가 제공한 한국어 신세계역 2014년 개정판·2026년 인쇄본이다. 다른 교파나 일반 역사학의 연대를 기본값으로 혼합하지 않는다. 같은 기관의 자료를 대조한 것을 독립적인 역사학적 입증이라고 부르지 않는다.

## 자료가 완성된 범위

마지막 파일은 172쪽이며 히브리서 5:13부터 앞 파일과 연결된다. 네 파일 합계는 1,772 PDF쪽이다. 성경 일람표는 누적 PDF1658쪽, ‘가6 도표: 유다와 이스라엘의 예언자와 왕’은1743~1744쪽에서 확인했다. 일부 부록은 가로로 된 펼침면이고 텍스트 추출 시 한글이 깨지므로, 실제 페이지를 이미지로 렌더링해 확인했다. 부록의 쪽수는 **네 파일을 합친 누적 PDF 위치**이며 종이책 인쇄 쪽수가 없는 펼침면도 있다. 사이트에는 파일 안 쪽수와 누적 PDF 쪽수를 함께 표시한다.

## 새로 찾은 왕명·도표 해석 문제

- 열왕기상16:9~23(첫 파일494쪽)과 가6은 **지므리**라는 이름과 오므리·디브니의 왕권 경쟁을 제시한다. 초안의 ‘시므리’를 정정하고 경쟁기를 생략하지 않는다.
- 본문 열왕기하17장(532쪽)의 왕명은 **호셰아**, 가6의 같은 왕 표기는 **호세아**이다. 제공 판본 내부의 표기 차이를 보존하고 국가·역할로 동일 인물을 식별한다. 예언자 호세아와 무작정 같은 인물로 합치거나, 표기의 한쪽을 외부 자료 없이 오자라고 단정하지 않는다.
- 도표는 공동·경쟁·단독통치 기간을 나누어 제시하고 일부 경계에 ‘경’과 설명을 붙인다. 이를 무시한 재위연수 합산으로 동시대 관계를 만들지 않는다.
- 요엘 카드를 앞선 엘리사·예후 흐름 뒤, 북왕국 말기의 넓은 기간과 겹치는 위치에 한 번 연결했다. 겹침을 명시하며, 새로운 사건을 일직선으로 연속 확정한 배열이라고 설명하지 않는다.

## 직접 표기와 계산의 구분

`private-import/pdf-audit/chronology-calculations.json`에 기준점·본문 연수·계산과 한계를 기록했다.

- 홍수 시작: 부록 나2의 아담4026년에서 창세기5장의 부자 간 출생 연수와7:6의 노아600년을 합한1656년을 빼면2370년이다. 부록에 같은 결과값이 직접 쓰여 있다고 주장하지 않고 ‘연수 계산’으로 표시한다.
- 족장 생애: 요셉 사망1657년과110세, 요셉이 파라오 앞에 섰을 때30세, 풍년7년·기근2년, 가족 도착 때 야곱130세, 야곱 출생 때 이삭60세를 연결한 연단위 계산을 따로 기록했다. 성구는72·96·102·105·110쪽에서 대조했다. 생일·달력 경계까지 확정한 날짜라고 표현하지 않는다.

출처에서 직접 대조한 값은 ‘출판물 대조’, 본문 재위년은 ‘PDF 성구 대조’, 계산으로 연결한 값은 ‘근거 대조·연수 계산’으로 구분한다. 날짜의 정밀도와 근거 확인 여부는 서로 다른 개념이다. 출처 자체가 추정하면 대조 완료 후에도 추정 표시가 남는다.

## 현재 자료와 남은 범위

요엘을 추가해 사건 지도는35개 사건이다. 사건 요약 전체의 상태는 여전히 초안이며, 확인한 연대 표기·명시된 범위·한정된 인물 연결만 단계적으로 대조했다. 새 파일의 표와 지도는 절대연대 확인에 필요한 자료를 많이 제공하지만, 원문 전체의 해석과 모든 교차 배치가 끝났다는 뜻은 아니다.

성경 일람표는 집필시기와 사건범위를 혼동하지 않는 데 핵심이다. 시편·잠언·예언서의 기록완료연도를 그 책 속 모든 사건의 연대로 쓰지 않는다. 이후 검증도 여호와의 증인 공식 자료를 기준으로 하고, 관련 출판물의 추가 설명이 필요한 항목은 남겨 둔다. 최신 온라인 설명과의 대조 및 전문 저장·재제공 이용 조건 확인은 온라인 접근 제한 때문에 아직 완료하지 않았다.

정정 자료는 비공개 `private-import/bible-verification-update.sql`에 갱신했다. 아직 초기 등록 전이면 갱신된 `bible-setup.sql`을 사용한다. 운영 DB에 자동 적용하지 않았다. 오프라인 서가에는 온라인에서 다시 저장해야 반영된다. 원본 PDF, 지도 이미지와 본문 추출물은 공개 배포물에 포함하지 않았다.

개정판의 책 이름·고유 명사 설명은1659쪽에서도 확인했다. 이전 판의 ‘재판관기’ 등을2014년 한국어 개정판에서 ‘사사기’ 등으로 바꾼 이유가 명시되어 있다. 서로 다른 판본의 표기를 무심코 혼합하지 않는다.

검사 범위: 자료 파서 단위 검사4개, 성경 읽기 화면 검사5개, production 오프라인 재시작 검사를 실행했다. 이 기술 검사는 내용의 역사적·해석적 검증을 대신하지 않는다. 실제71건의 근거 기록과35개 사건을 수입하고, 기존 사건 수정과 신규 요엘 추가가 반복 실행되어도 중복되지 않는지 격리된 PostgreSQL에서 검사했다.
