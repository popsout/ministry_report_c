# 족장 시대 요약 확충 1차

제공된 한국어 신세계역 네 PDF를 기준으로, 35개 통합 사건 중 족장 시대의 4개를 소개 문장 수준에서 여러 문단의 학습 요약으로 확충했다. 새 성경 번역이나 본문 복제가 아닌 직접 작성한 사건 요약이다. 전체 사건은 계속 초안 상태이며, 최신 공식 출판물의 세부 해설 검증 완료를 주장하지 않는다.

- 아브라함: 이주, 롯과 멜기세덱, 계약과 약속, 소돔과 그랄, 이삭의 출생과 시험, 다음 세대로의 연결.
- 이삭·야곱: 약속의 계승, 축복과 출발, 가족 형성, 귀향과 이스라엘이라는 이름, 가나안의 가족 사건.
- 요셉: 팔려 감, 감옥, 식량 관리, 형제들과 재회, 이집트 이주, 약속의 땅에 대한 희망.
- 욥: 사탄의 주장, 고난, 세 친구·욥·엘리후의 발언 구분, 여호와의 말씀과 결말. 세 친구의 말을 모두 하느님의 가르침으로 취급하지 않는다.

창세기 개요 41~42쪽과 관련 본문, 욥기의 관련 본문을 대조해 특정 사항에 대한 원문 근거 21건을 추가했다. 자료 전체는 35개 사건·8개 시대·근거 98건이다. 근거 수는 검증 완료된 사건 수가 아니다. 왕국 성립 전의 야곱·가족과 후대 왕국을 구분하며, 두 아비멜렉을 동일 인물로 단정하지 않는다. 욥의 세부 연도와 창세기의 생애·계보를 억지로 일렬로 고정하지 않는다.

기존 `summary` 문자열에 문단 구분을 저장하므로 새 DB 열이나 관리자 권한 설정은 필요 없다. 화면은 빈 줄로 구분된 문단을 각각 표시하며, 이전 데이터와 암호화 서가의 형식도 그대로 읽는다.

운영 사이트의 기존 자료 변경은 소유자가 개인 산출물 `private-import/bible-patriarchs-update.sql`을 SQL Editor에서 실행해야 한다. 4개의 기존 사건이 있는지 먼저 확인하고, 해당 사건의 요약·관련 왕·성구·배치 안내·근거만 트랜잭션 안에서 갱신한다. 관리자 등록·정책·봉사 기록은 변경하지 않는다. 초기 설정과 전체 정정 파일도 최신 내용을 포함하도록 갱신했다. 새 자료를 오프라인에서도 읽으려면 온라인에서 서가를 다시 저장한다.

그 외 31개 사건은 이번 확충 대상에 포함하지 않았다. 후속 작업은 출애굽·광야부터 시대별로 같은 방식으로 보완하는 것이다. 실제 사건 JSON, SQL 및 독립 미리보기 HTML은 Git과 공개 앱 번들에 넣지 않는다.
